# **App Name**: Bonito Landing

## Core Features:

- Hero Section: Display the main book title and subtitle with call-to-action buttons, creating an engaging first impression.
- Animated Text Blocks: Show key insights of the book with fade-in and slide-in animations for an immersive reading experience.
- Core Value Columns: Visualize the three values with supporting minimal icons and brief descriptions.
- Author Video Carousel: Show a series of clips of the author's comments regarding the topic
- Highlighted Book Extracts: Display notable quotes or passages in a typewriter-like animation, providing reflective pauses.
- Call to Action Block: Offer purchasing choices for buying in hardcopy, digital form, or audiobook, connecting straight to sales platforms.
- Accessibility adjustment: Offer the users control on text sizes to facilitate reading

## Style Guidelines:

- Primary color: Inspired by the logo, use a muted coral red (#E97451) to convey warmth and trustworthiness. This evokes the feeling of compassionate negotiation.
- Background color: Light desaturated peach (#F2DACB) to create a calm and inviting canvas.
- Accent color: Soft lavender (#B19CD9) to add a modern touch, and help distinguish buttons from the surrounding peach.
- Headline Font: 'Montserrat' (sans-serif) for headings, as specified by the user. Note: currently only Google Fonts are supported.
- Body Font: 'Alegreya' (serif) provides great legibility when paired with 'Montserrat' headlines.
- Minimal, elegant icons that reflect each principle's essence.
- Ensure that the page elements are easy to navigate.
- Delicate transitions, creating movement and a memorable user experience.
